# Contributing

This is a reference implementation. It shows one way to run Anthropic's
commerce-agents blueprint against a live Shopify store, and it tracks the blueprint
at the commit pinned in `requirements.txt`.

We're glad for bug reports and questions — please open an issue. We are not accepting
pull requests at this time.

Security issues: please report through
[Shopify's security program](https://hackerone.com/shopify) rather than a public issue.
